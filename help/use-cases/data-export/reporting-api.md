# API de informes

Este artículo describe cómo se puede usar [!DNL Customer Journey Analytics Reporting API] para implementar el siguiente [caso de uso de exportación de datos](overview.md):

- Integración de aplicaciones personalizadas

## Introducción

[!DNL Customer Journey Analytics Reporting API] le permite recuperar mediante programación las mismas dimensiones y métricas procesadas disponibles en Analysis Workspace. Use [!DNL Reporting API] para activar aplicaciones personalizadas, incrustar informes en herramientas internas o automatizar la recuperación de datos de Customer Journey Analytics sin necesidad de exportar manualmente.

## Más información

[!DNL Reporting API] usa el mismo formato de solicitud y respuesta que [!DNL Adobe Analytics] [!DNL Reporting API], pero usa un extremo diferente. Si está migrando integraciones de informes desde [!DNL Adobe Analytics], consulte el flujo de trabajo de migración en la [Guía de inicio rápido](/help/getting-started/cja-getting-started.md) para obtener más información.

Para obtener información sobre la autenticación, los extremos disponibles y los límites de solicitudes actuales, consulte la [documentación de la API de Customer Journey Analytics](https://developer.adobe.com/cja-apis/docs/).
